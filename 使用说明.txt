Lovable 静态网站导出工具 3.1

一、完整解压后运行 LovableStaticExporter.exe。电脑需安装 Node.js（含 npm），保留 export.mjs 和 news.mjs。
二、选择项目目录，或输入目录后点击“加载项目”。
三、SEO / 栏目设置：填写全站关键词、首页描述、正式网址；启用新闻并编辑栏目名称、简介、每页篇数。
四、新闻内容管理：添加 / 编辑 / 删除新闻，设置标题、文件名、日期、摘要、独立关键词、正文和最多一张图片。
五、正文为纯文本，空行分段；图片支持 PNG、JPEG、GIF、WebP，最大 20 MB。文章关键词留空则继承全站关键词。
六、点击“保存设置和新闻”保存草稿。点击“保存并导出 HTML + ZIP”，生成项目下 dist 和 dist.zip。
七、将 dist 内全部文件上传 IIS 根目录。更新后同步整个目录，清理服务器上已删除的旧新闻。

八、首次配置 SFTP：将 server 文件夹复制到 Windows Server，运行 SftpServerSetup.exe。
选择官方 OpenSSH-Win64.zip、网站目录、专用用户、允许的客户端公网 IP、端口。管理员 PowerShell 会提示设置新账号密码。
已有 sshd 服务可复用；云服务器安全组还需放行对应端口。详细步骤见 server/README.md。

九、本机工具“SFTP 服务器发布”填写主机、端口、账号、密码和远程目录，例如 /C:/inetpub/britecard。
点击“获取并核对指纹”，与服务器可信控制台的 SHA-256 内容核对一致后保存，再测试连接。
可改用 PuTTY .ppk 私钥，OpenSSH 私钥需先用 PuTTYgen 转换。可选记住口令，使用 Windows 当前用户加密。
十、点击顶部“构建并上传服务器”，构建成功后自动上传 dist；也可只上传现有 dist。
默认保留服务器额外文件。可选清理本工具部署清单记录的旧新闻；不会删除其他服务器文件。
连接设置只保存在本机，不写入项目或网站 ZIP。上传按文件更新，中断后可重试，不是整站原子切换。

3.1 已加入独立 Logo、EXE / 窗口图标与版本信息。当前构建仍未签名，不能仅凭换图标解除 Windows 警告。
公开发行需要用真实可信代码签名证书签名，并添加时间戳；新签名程序也可能需要积累 SmartScreen 信誉。
仓库完整源码提供 sign-release.ps1 正式签名入口；运行包提供 SHA256SUMS.txt，仓库另有 ZIP 校验码。说明见 SIGNING.md。
如果 Defender 提示具体威胁名称，需另看检测记录，不应简单当作未签名。不要为此关闭系统安全防护。

栏目首页展示最新 3 篇，列表按日期倒序自动分页。文章生成独立 news/文件名.html。
首页原布局保留，在底部添加新闻区块；有 header nav 时添加栏目入口。新闻页继承首页 CSS、字体和主题变量。
全站关键词会写入导出 HTML；新闻页独立设置标题、描述、关键词。正式网址用于 canonical 和新闻 sitemap。
SEO 标签不保证搜索排名或收录。

编辑内容与图片保存在项目 .static-exporter 目录，下次加载可继续编辑，请随项目一起备份。
原网站源码不被修改；旧 dist 自动备份。后端 API、登录、数据库不属于静态导出范围。
仅支持普通 Vite 和 Lovable TanStack 配置；原站已有 news 目录时会提示冲突。更多说明见 README.md。
